The Problem & The Solution

Why HDI development is hard — and how HDI-Agent changes that

❌ Without HDI-Agent

  • Must know 30+ artifact types and their exact file extensions
  • Write HDI DDL by hand — one syntax error fails the entire deploy
  • Manually maintain .hdiconfig plugin registry for every new type
  • Call DI API in exact order: WRITE → MAKE → GRANT
  • Manually grant privileges before DBX data preview works
  • Debug silent failures by reading internal M_MESSAGES tables
  • Special handling needed for CVs, Libraries, VTs — undocumented quirks
  • ⏱ 5–15 minutes per artifact

✅ With HDI-Agent

  • Describe in plain English — GPT-4o generates correct HDI syntax
  • Agent reads artifact documentation and produces valid DDL automatically
  • .hdiconfig managed automatically — zero manual plugin setup
  • Full WRITE → MAKE → GRANT sequence handled with error recovery
  • Privileges granted automatically — DBX data preview works instantly
  • M_MESSAGES queried and logged automatically for diagnostics
  • Built-in special handling for CVs, Libraries, Virtual Tables
  • ⚡ Under 30 seconds per artifact
Bottom line: HDI-Agent reduces artifact deployment time by 90%+, eliminates syntax errors, and makes HANA HDI accessible to anyone — no DI API knowledge required.
