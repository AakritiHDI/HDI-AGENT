# hdbview — HANA HDI View Artifact

## Overview
An `.hdbview` file defines a **SQL view** as a design-time artifact in an HDI container.

## File Extension
`.hdbview`

## File Path in Container
`src/<VIEW_NAME>.hdbview`

## Syntax

```sql
VIEW "<VIEW_NAME>" [WITH STRUCTURED PRIVILEGE CHECK] AS
SELECT
    <column_expressions>
FROM "<TABLE_OR_VIEW>" [AS "<alias>"]
[JOIN "<TABLE_2>" AS "<alias>" ON <condition>]
[WHERE <condition>]
[GROUP BY <columns>]
[HAVING <condition>]
```

> **Important:** Do NOT include `CREATE` before `VIEW`.

## Examples

### Simple view
```sql
VIEW "EMPLOYEES_VIEW" AS
SELECT
    "EMPLOYEE_ID",
    "FIRST_NAME" || ' ' || "LAST_NAME" AS "FULL_NAME",
    "EMAIL",
    "DEPARTMENT_ID"
FROM "EMPLOYEES"
WHERE "ACTIVE" = 1
```

### View with JOIN
```sql
VIEW "EMP_DEPT_VIEW" AS
SELECT
    e."EMPLOYEE_ID",
    e."FIRST_NAME",
    e."LAST_NAME",
    d."DEPARTMENT_NAME",
    e."SALARY"
FROM "EMPLOYEES" AS e
INNER JOIN "DEPARTMENTS" AS d
    ON e."DEPARTMENT_ID" = d."DEPARTMENT_ID"
```

### Aggregation view
```sql
VIEW "DEPT_HEADCOUNT_VIEW" AS
SELECT
    d."DEPARTMENT_NAME",
    COUNT(e."EMPLOYEE_ID") AS "HEADCOUNT",
    AVG(e."SALARY")        AS "AVG_SALARY",
    MAX(e."SALARY")        AS "MAX_SALARY"
FROM "DEPARTMENTS" AS d
LEFT JOIN "EMPLOYEES" AS e
    ON e."DEPARTMENT_ID" = d."DEPARTMENT_ID"
GROUP BY d."DEPARTMENT_NAME"
```

### View with analytic privilege check
```sql
VIEW "SECURE_SALES_VIEW" WITH STRUCTURED PRIVILEGE CHECK AS
SELECT "ORDER_ID", "CUSTOMER_ID", "TOTAL_AMOUNT", "REGION"
FROM "ORDERS"
```

## Rules
- Start directly with `VIEW` — never write `CREATE VIEW`.
- Column aliases must be quoted if they contain spaces or special characters.
- To reference objects outside the container, use `.hdbsynonym`.
